# Knowledge Base — Developmental Milestones

> **Educational information, not medical advice.** See `docs/02-Research/28-MEDICAL_DISCLAIMER.md`.

## Purpose
Educational content for developmental milestones using the CDC "Learn the Signs. Act Early." 2022 checklists (2 months–5 years) — supporting the milestones module (`docs/06-Modules/91-MILESTONES_MODULE.md`) and development timeline (`docs/08-Timeline/115-DEVELOPMENT_TIMELINE.md`).

## Scope
- Milestone checklists by age (2,4,6,9,12,15,18,24,30 months; 3,4,5 years) — "what most children do by this age" (≥75% framing).
- Supportive "act early" guidance; corrected age for preterm.

## Governance
- Only the CDC 2022 set is used (`docs/02-Research/26-DEVELOPMENTAL_MILESTONES.md`).
- Non-diagnostic: not-yet-met → supportive clinician-review ("act early"), never a delay/disorder diagnosis.
- Typed + sourced; celebratory tone for achievements.

## Sources
CDC Developmental Milestones (2022); Zubler et al., Pediatrics 2022 — see `docs/02-Research/26-DEVELOPMENTAL_MILESTONES.md`, `27-REFERENCES.md`.
